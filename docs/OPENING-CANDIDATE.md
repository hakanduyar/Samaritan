# Experimental opening

The existing `/samaritan` route remains unchanged. `/opening-candidate` is an opt-in preview of an authored opening sequence: genuine asset loading, a short connection banner, travel through the scene, commands displayed on an existing pane, and return to the interactive scene.

The opening uses the same authored world and synthetic imagery, not television footage. Timing is an adaptation, not a measured reproduction of the show. The final SAMARITAN word is branding. The outlined loading bar is indeterminate; it does not claim a download percentage. Loading failures show an error.

One foreground clock excludes hidden-tab time. Early navigation cannot accumulate a jump during the opening. Reduced motion skips camera travel and return while retaining a finite command dwell. The approached pane keeps its geometry and morph animation; a canvas texture supplies readable commands through the return. Only the opening vignette fades out around the command hold; the interactive vignette is unchanged.

## Review limits

Source and actual-asset parsing tests cover readiness, hidden pause, early input, pane material continuity, camera handoff and vignette boundaries. These tests do not render GPU pixels. Limited desktop observations found upright command text, a clean white command frame and a return to the world. Full uninterrupted use, portrait framing, slow-load errors and motion comfort remain open. The world retains its authored16:9 aspect and may have bars in portrait.

This remains an experimental route until whole-use review. Reverting the opening feature removes its route/runtime option and compatible opening asset together; it need not revert navigation, ambient motion or the existing scene asset. No renderer/framework replacement is introduced.
